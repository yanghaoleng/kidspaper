# 参考页设计与交互拆解

来源：[Averie · 很高兴认识你](https://averie-little-world.averieh0202.chatgpt.site/)。采集与核对日期：2026-10-20。

## 获取证据

本地浏览器、普通抓取和两个服务器出口均被 Cloudflare 拦截。通过 Vercel 的临时美国云环境（响应节点 IAD）成功获取 HTTP 200：页面 HTML、两份样式、主交互脚本、五个依赖模块、登录样式、公开的展示数据和 1672×941 主插画。共 12 个公开资源。

将这些公开资源放在本机只读预览中，实测了前端互动。未登录原站、未支付、未调用原站 AI，也未获取任何私有账户信息。原始源码、数据与截图仅保存在不进入仓库的 artifacts 和 local-reference 目录，未作为本项目许可证下的源码或素材再发布。

## 已核对的小交互

1. **风景热点**：五个可点击对象，点击打开右侧故事面板。其中人物直接打开档案对话。热点有 9px 小圆点和手绘感虚线文字，悬停扩展光圈。线索开关隐藏标签，悬停或键盘聚焦时仍可显示。
2. **故事到证据的路径**：故事面板可展开原始回答，再跳到画像维度，或带着当前话题进入聊天。
3. **画像地图**：四象限、性格、价值三个页签；点图形或维度按钮，同步更新右侧解释。右侧再分“解释 / 原始回答 / 日常建议”三个层级。
4. **关系情境切换**：不同关系角色切换对应表达、边界、易卡住的地方与沟通建议；不只替换标题。
5. **沟通练习**：三个情境按钮切换“原来的说法 / 更能被听懂的说法 / 为什么”。
6. **兴趣选择**：圆形兴趣按钮可切换选中状态、勾选符号和下方话题；轻微上移 4px，过渡约 250ms。
7. **手机横向探索**：保留完整场景，不简单裁成一张竖图。390px 视口下场景宽 1528px、高 860px；快捷按钮定位海边、人物、烤鱼、伴侣和房车。实测定位房车后 `scrollLeft` 约 981.5px，页面本身没有横向溢出。
8. **微动效**：水面慢速 9s 呼吸移动，烤架蒸汽 5s 轮流上升；尊重 reduced-motion 设置。
9. **对话边界**：明确区分 AI 档案与本人；未写下的事不知道。后端登录、云存储、支付和模型服务仅阅读了公开前端说明，未验证可用性。

## 儿童版的转译

保留“生活场景 → 主动点开了解 → 回到原话 → 日常陪伴”的层次。把成人关系角色改为孩子表达、家长心声、共同想象；把人格刻度与阶段等级改为有出处的文字观察。保留轻盈的水彩场景、宋体、纸张留白、热点侧栏和手机探索，增加家长原信、加密长期收藏与档案对话。

儿童版不复用成人人格评分、不复制原站个人故事与艺术素材。所有产品文字、绘本与交互代码重新创作。
